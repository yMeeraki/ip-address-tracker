# IP Address Tracker

A simple and responsive IP Address Tracker that displays the IP address, location, timezone, ISP, and map location using an IP geolocation API.

## Features

- Search any IP address
- Display location and ISP details
- Show timezone information
- Interactive map with location marker
- Responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- IP Geolocation API
- Leaflet.js
